\# Library Demo Run Guide



\## Prerequisites

\- Python 3.9 or later.

\- JDK 17 or later, with both java and javac available on PATH.

\- A local copy of this repository.



\## Run the demo

Open a terminal in the repository root (the folder containing run.py):



```bash

python3 run.py demo

```



On Windows, you can use:



```bat

py -3 -X utf8 run.py demo

```



\## What the demo does

The demo uses the fixed date 2026-09-01. It displays student and

faculty borrowing limits, searches for "git", and shows Alex borrowing

"Git Essentials" with a due date of 2026-09-15. It then returns the book,

showing a return fee of 0 and no remaining active loans.
